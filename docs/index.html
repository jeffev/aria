Funcionalidades

Tudo que você precisa,
em uma só tela

Projetado para quem quer centralizar sua rotina sem depender de dezenas de apps diferentes.

🤖

Chat com IA (Gemini)

Conversa em texto ou voz usando a Web Speech API. A ARIA tem acesso ao seu contexto real — tarefas e eventos — para respostas relevantes.

📅

Agenda semanal

Visualização seg–dom com CRUD completo. Sincroniza com o Google Calendar via OAuth 2.0, mantendo eventos externos somente leitura.

✅

Gerenciador de tarefas

Prioridade Alta / Média / Baixa, prazos, alerta visual de atraso e filtros por status. Ordenação automática por urgência.

📝

Notas com autosave

Editor livre com salvamento automático (debounce 800ms) e fixação de notas no topo. Preview de conteúdo na lista.

🌤️

Widget de clima

Open-Meteo API — gratuito, sem chave. Usa geolocalização do browser para exibir temperatura, sensação térmica e condição atual.

🔍

Pesquisa global

Atalho Ctrl+K abre busca simultânea em tarefas, eventos e notas com debounce de 300ms e navegação direta.

🔔

Notificações nativas

Alertas do sistema operacional para eventos nos próximos 15 minutos, sem repetição na sessão. Zero dependência de serviços externos.

🖥️

Overlay desktop

Janela flutuante sempre visível via Electron. Atalho Ctrl+Shift+A abre/fecha o painel sem tirar o foco do que você está fazendo.

Instalação

Rodando localmente

Web app e overlay desktop rodam separadamente. Siga os passos abaixo para cada um.

Pré-requisitos

🟩
Node.js
Versão 20 ou superior
Download
🐋
Docker
Para o banco PostgreSQL local
Download
✦
Google Gemini API Key
Plano gratuito disponível no AI Studio
Obter chave
1

Clone o repositório

git clone https://github.com/jeffev/aria.git cd aria
2

Suba o banco de dados

Inicia o PostgreSQL 16 via Docker Compose na porta 5432.

docker compose up -d
3

Configure as variáveis de ambiente

Copie o template e preencha as chaves necessárias.

cp app/.env.example app/.env.local
DATABASE_URL
Connection string do PostgreSQL local (já preenchida no .env.example)
GEMINI_API_KEY
Chave do Google AI Studio
↗ Obter
GOOGLE_CLIENT_ID
GOOGLE_CLIENT_SECRET
OAuth 2.0 para Google Calendar (opcional)
↗ Google Cloud Console
DISCORD_TOKEN
MICROSOFT_*
Integrações opcionais — deixe em branco para ignorar
4

Instale as dependências e rode as migrations

cd app npm install npx prisma migrate dev
5

Inicie o servidor de desenvolvimento

npm run dev # Acesse em http://localhost:3000
1

Acesse a pasta do overlay

cd desktop
2

Instale as dependências

npm install
3

Inicie o overlay

O Electron abre uma janela flutuante sempre visível. Use o atalho para mostrar/ocultar.

npm run dev # Atalho para abrir/fechar: Ctrl+Shift+A
!

O web app precisa estar rodando

O overlay consome a API do web app. Certifique-se de que o npm run dev da pasta app/ já está ativo antes de abrir o overlay.
